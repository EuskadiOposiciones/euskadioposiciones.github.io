# EuskadiOposiciones — home matriz

Home estática para `euskadioposiciones.com`, pensada como marca matriz de las verticales actuales de Osakidetza y UPV/EHU.

## Despliegue

Subir el contenido de este directorio a la raíz del repositorio `euskadioposiciones/euskadioposiciones.github.io` y publicar GitHub Pages desde `main / root`.

El archivo `CNAME` debe permanecer con:

```text
euskadioposiciones.com
```

## Asesoramiento personalizado

No se publica en esta versión. Se incorporará cuando esté automatizado el circuito de recepción y seguimiento por email.
